# Edge-Center/.github

This repository holds the files GitHub reads on behalf of the whole organization.
There is no product code here.

| Path | What GitHub does with it |
| :--- | :--- |
| [`profile/README.md`](profile/README.md) | Rendered on [github.com/Edge-Center](https://github.com/Edge-Center) above the repository list |
| [`profile/assets/`](profile/assets) | Hero artwork, one file per color scheme, self-contained SVG |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Shown when someone opens an issue or a pull request in any repository without its own copy |
| [`SECURITY.md`](SECURITY.md) | Backs the Security tab in those repositories |
| [`SUPPORT.md`](SUPPORT.md) | Linked from the issue chooser |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request body |

A repository that ships its own version of any of these wins - the defaults here
only fill gaps.

Developer documentation for the organization lives in
[edgecenter-docs](https://github.com/Edge-Center/edgecenter-docs).
